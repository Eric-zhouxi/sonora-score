# Sonora Score

Sonora Score 是一个先完成“创作与听谱”，再逐步走向智能扒谱的音乐工作台。当前版本专注第一阶段：管理多个作品、编写总谱与独立声部、试听并导入/导出 MIDI；扒谱模型不在本阶段的产品入口中。

## 当前功能

- 作品库主页：保存多个本地作品，提供独立样例，也能创建真正空白的新作品。
- 总秒时间轴：显示秒刻度和随播放移动的指针，支持拖动定位、缩放、节拍吸附和从当前位置播放。
- 片段编排：每个声部可建立多个片段，分别拖动起始时间、精确输入秒数，或在选中音符处分割片段。
- 声部管理：支持钢琴、第一/第二小提琴、大提琴和长笛；名称可直接修改，也可静音。
- 五线谱与简谱同步：显示调号、拍号、小节号、小节线、升降号、还原号、延音线和延音记号。
- 自动休止符：按各声部独立拍号补齐开始、片段之间及结束的空档；跨小节音符自动拆分并加延音线。删除音符保留其他音符的实际时间。
- 音符编辑：支持全、二分、四分、八分、十六分音符，选择音符后可升降半音或删除。
- 清晰的音符输入：先选八度、时值、升降记法，再点击琴键；琴键同时标科学音高和简谱唱名。
- 独立调性与拍号：每条音轨可使用 15 种大调调号和 10 种常见拍号，同类乐器的声部互不覆盖；提供整声部移调与半音移调。
- 总谱生成：勾选任意声部生成一份时间对齐的多谱表总谱，保留各自的调号、拍号与休止符，支持下载独立 SVG 文件。
- 深色界面：不同轨道使用柔和明亮的青绿、紫、橙等配色，同类乐器也分配不同颜色；颜色可以自定义。
- 播放：四种乐器使用本地采样音色，加载失败时自动回退为合成音色；延音线与延音记号会反映到播放时值中。
- MIDI：支持标准 MIDI 导入和导出，作品自动保存在浏览器本地。

## 推荐体验路径

1. 在主页点“＋ 新建作品”，确认进入只有一条空钢琴声部的新作品。
2. 进入“声部编辑”，输入几个音符。拖动播放指针到 3 秒，点“在当前位置新建片段”，输入第二段旋律。
3. 在“时间轴”中前后拖动第二个片段，第一段保持原位；拖动青色指针后点击播放，从该位置开始。
4. 回到“声部编辑”，检查片段之间是否自动出现休止符，也可精确填写“片段起始秒数”。
5. 添加第二条钢琴音轨；分别设置 D 大调 / 3/4 与 F 大调 / 7/8。要改变实际音高，使用“移调到”和“移调整个声部”。
6. 勾选两条音轨的“加入总谱”，点击“生成总谱”，查看独立谱表及下载 SVG。
7. 直接编辑左侧声部名称，用 ↑↓ 排序；第一/第二小提琴可继续添加。

## 本地运行

要求 Node.js 20 或更新版本。

```bash
npm install
npm run dev
```

浏览器打开终端显示的本地地址，默认通常为 `http://localhost:5173`。

构建与测试：

```bash
npm test -- --run
npm run build
npm run test:e2e
```

端到端测试在 Windows 使用已安装的 Microsoft Edge，在其他系统使用 Playwright Chromium（首次运行先执行 `npx playwright install chromium`）。

所有音轨共享一个四分音符 BPM 和秒时间线。不同拍号按照自己的拍值划分小节，并保留在独立谱表上；合谱不会为了对齐小节而改变旋律的实际播放时间。简谱采用首调记法并显示 `1 = 调号`。MIDI 保留音高和绝对起音，但标准 MIDI 不保存本应用的片段分组或独立谱表外观；完整编辑设置会保存在本机作品库中。

## 交互设计依据

编辑模式参考成熟制谱软件中“先在开始中心建立/打开乐谱，再区分选择编辑与音符输入”的工作流。具体调研与本项目中的取舍见 [`docs/product-research.md`](docs/product-research.md)。

## 声源原则

仓库不提交大型原始采样包。当前 Tone.js Sampler 使用经过裁剪、单声道化和重采样的 University of Iowa A4 钢琴、小提琴、大提琴和长笛录音，并用自动移调覆盖键盘；来源、许可与校验和记录在 `assets/samples/manifest.json`。

## 后续阶段

扒谱模型、乐器识别和和弦识别属于下一阶段，目前暂停开发。仓库保留早期实验与架构资料，但不会干扰当前创作工作台。
