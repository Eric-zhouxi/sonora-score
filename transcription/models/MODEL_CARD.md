# timbre-pitch-v0.1

## 用途

这是用于打通 Sonora Score 训练、版本化、推理和评测链路的单音 smoke 模型。它同时完成：

- 钢琴 / 小提琴二分类；
- C4–B4 十二个 MIDI 音高分类。

音色头是标准化声学特征上的 softmax 回归；音高头是从训练数据学习的一维音高码本。输入特征包含基频、谐波包络、谱质心、滚降、平坦度、起音位置、延音比和过零率。

## 训练数据

`synthetic-smoke-v1`：代码生成的钢琴型衰减谐波与小提琴型持续/颤音谐波。每个音色和音高使用不同相位、力度、失谐、噪声及短混响变体。模型没有使用受版权保护的商业歌曲。

## 已知限制

- 只覆盖两种音色和一个八度，不支持把同类小提琴分配到多个声部。
- 合成测试集与训练生成器同域，100% 仅证明管线可学习，不代表真实音乐性能。
- Iowa 真实集当前只有单一来源的八条样本，只能验证最小域外链路。
- 混音歌曲应先经过源分离；当前主乐器判断不能替代 stem 级分类。

完整数字见 `transcription/reports/`，可通过 `python -m sonora_analysis.train` 重建。

## v0.1 指标

- 合成训练集：288 条；合成测试集：96 条。
- 合成测试 instrument accuracy / macro-F1 / pitch accuracy：1.0 / 1.0 / 1.0。
- Iowa 域外 smoke：8 条；instrument accuracy 0.875、macro-F1 0.873、pitch accuracy 1.0。唯一错误是把小提琴 G4 判为钢琴。
